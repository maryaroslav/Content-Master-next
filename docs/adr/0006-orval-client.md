# 0006. Generate the API client with orval (D6)

Status: Accepted

## Context

The web app called the API through hand-written `fetch` and axios calls with hardcoded URLs and untyped responses.

## Decision

`@cm/api-client` is generated by orval from the OpenAPI document: TanStack Query hooks, models and, for tests, MSW handlers (`@cm/api-client/mocks`). A custom axios mutator adds the base URL and the access token and retries once after a shared refresh on 401.

## Consequences

- The web app uses generated hooks only; no hardcoded API URLs.
- Generated code is gitignored and regenerated by the `generate` turbo task.
- orval 8.40 emits MSW 2 imports, so tests stay on MSW 2 until orval supports MSW 3.
