# Content Master

A small social network: posts with images, communities, events, following, a real-time private chat, two-factor authentication, English and Czech UI.

The requirements and the design are described in [`Content Master SRS.docx`](Content%20Master%20SRS.docx) and [`Content Master SDD.docx`](Content%20Master%20SDD.docx) (Czech); the architecture decisions are in [`docs/adr`](docs/adr/README.md). How to add endpoints, events, migrations and tests: [CONTRIBUTING.md](CONTRIBUTING.md).

## Stack

- **Web** (`apps/web`): Next.js 16 App Router with the React Compiler, TanStack Query, react-hook-form 8 with zod, next-intl (`en`, `cs`), Socket.IO client.
- **API** (`apps/api`): Express 5, Sequelize with umzug migrations, MySQL 8, Socket.IO, JWT access tokens with rotating refresh cookies, TOTP 2FA, sharp for images.
- **Shared**: zod contracts that generate the OpenAPI document, an orval-generated client, typed Socket.IO events.
- **Tooling**: pnpm workspaces, Turborepo, Vitest, Testing Library, MSW, Playwright, ESLint, knip, dependency-cruiser, syncpack, husky, GitHub Actions. JPEG files are stored with Git LFS.

## Requirements

- Node.js 24 (see `.nvmrc`)
- pnpm, the version pinned in `package.json`: `corepack enable`
- MySQL 8

## Setup

```sh
pnpm install
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env.local
```

In `apps/api/.env` fill in the database credentials, `JWT_SECRET` and `TWOFA_ENCRYPTION_KEY` (both `openssl rand -hex 32`). The variables are validated on startup and the API lists what is wrong.

In `apps/web/.env.local`, `API_ORIGIN` is where the web server forwards `/api/v1/*` and `/uploads/*`; `API_URL`, `APP_ENV` and `REALTIME_URL` reach the browser through `/env.js`. All of them are read at runtime, so one build runs in every environment.

```sh
pnpm dev
```

Starts the web app on http://localhost:3000 and the API on http://localhost:5001. Pending migrations are applied before the API starts.

## Commands

```sh
pnpm dev                 # all apps in watch mode
pnpm build               # build everything
pnpm typecheck | lint | circular
pnpm test                # unit and web component tests (no database)
pnpm test:integration    # API tests against a throwaway MySQL database
pnpm test:e2e            # Playwright against built apps on ports 3100/5101 and a throwaway database
pnpm knip                # unused files, exports and dependencies
pnpm syncpack:check      # dependency version rules

pnpm --filter @cm/api db:migrate | db:rollback | db:status
```

Before the first `pnpm test:e2e`, install the browser: `pnpm --filter @cm/e2e exec playwright install chromium`.

The pre-commit hook runs typecheck, lint, circular and the unit tests for the changed packages. CI runs these plus build, integration tests, knip and syncpack, and the end-to-end tests in a parallel job.
